1. One definition of "idle app" (src/deskflow/remediation/apps.py: find_idle_apps)
Scan's Background apps category and the fix action close_idle_apps must both call it.
Today scan reports 0 idle apps while fix offers 36 processes holding 5.7 GB.
- Candidates are user-facing apps only:
  Windows: processes that own at least one visible top-level window with a non-empty title
  (EnumWindows, IsWindowVisible, GetWindowThreadProcessId via ctypes inside
  platform/windows.py). Helper and service processes without windows are never candidates;
  group by executable name and sum the group's CPU and RSS.
  macOS: list apps with background-only false through osascript (System Events, 5 s
  timeout). If it fails, offer no app-closing action and say why. This path is best effort
  and cannot be tested locally; document that.
- A group is idle when its total CPU is under 2 percent at scan time, total RSS is at least
  300 MB, and it does not own the foreground window (Windows GetForegroundWindow, macOS
  frontmost app).
- NEVER_OFFER list per platform adapter (case-insensitive): terminals and shells, IDEs and
  editors (Code, Cursor, Antigravity, PyCharm, IntelliJ, Xcode), file manager and shell UI
  (explorer, Finder, Dock), security tools, presentation and conferencing apps (PowerPoint,
  Keynote, Zoom, Teams, OBS), the DESKFLOW process tree and all its ancestors.
- Closing is graceful. Windows: post WM_CLOSE to each of the group's visible top-level
  windows, wait up to 8 s, and report per group closed or still running (for example waiting
  at a save prompt). macOS: osascript quit for the application. Never TerminateProcess
  unless --force is given AND a second explicit confirmation is typed. Always list exact app
  names, counts and RSS before asking, and warn about unsaved work.
- end_busy_process uses the same NEVER_OFFER list and the same graceful-first escalation.
- Tests: window-owning versus windowless classification with a fake adapter, NEVER_OFFER
  respected, foreground exclusion, graceful path never calls terminate, force requires the
  second confirmation, scan and fix report identical idle groups for the same input.
